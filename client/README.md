# SmartLect — клиент

Flutter-приложение для iOS, Android и macOS: запись лекции с фото доски, загрузка,
прогресс обработки и просмотр конспекта с формулами.

## Запуск

```bash
flutter pub get
flutter run -d macos                     # или -d <id телефона/симулятора>
```

Адрес сервера по умолчанию — `http://localhost:8081` (эмулятор Android — `http://10.0.2.2:8081`).
С телефона нужен IP компьютера в той же сети: его можно поменять на экране входа
(«Сервер: …») или задать при сборке: `--dart-define=API_URL=http://192.168.1.10:8081`.

## Устройство

| Каталог | Что внутри |
|---|---|
| `lib/core` | HTTP-клиент с обновлением токена, хранение токенов (Keychain), адрес сервера |
| `lib/features/auth` | вход и регистрация |
| `lib/features/lectures` | список, карточка лекции, конспект / расшифровка / фото |
| `lib/features/recording` | запись, фото доски с таймкодом, локальные черновики |

Запись сначала сохраняется на устройстве (черновик), затем загружается по шагам:
создание лекции → аудио → фото → отправка на обработку. Каждый шаг запоминается, поэтому
без интернета запись не теряется, а после обрыва загрузка продолжается с того же места.

## Тесты

Сквозной тест на настоящем бэкенде (нужны `docker compose`, оркестратор и воркер с `WORKER_FAKE=1`):

```bash
flutter test integration_test -d macos
```

## Известные ограничения

- Android: долгая запись в фоне может быть остановлена системой — нужен foreground service.
- macOS: камеры в `image_picker` нет, фото доски выбираются из файлов.
- iOS и Android пока не собирались на этой машине (нет места под симулятор / Android SDK).
